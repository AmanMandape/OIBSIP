# Credit Card Fraud Detection

## Project Overview
This project analyzes transaction data and builds a machine learning model to identify potentially fraudulent credit card transactions.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Activities
- Transaction data exploration
- Fraud and legitimate transaction distribution analysis
- Feature analysis and visualization
- Data preprocessing and categorical encoding
- Random Forest classification with class balancing
- Model evaluation using precision, recall, F1-score, and confusion matrix
- Feature importance analysis
- Saving prediction results

## Project Contents
- `dataset/` — Transaction dataset, if included
- `notebook/` — Fraud detection notebook
- `output/` — Saved predictions and results

## Important Note
Fraudulent transactions are a minority of the dataset. Model performance should be assessed using precision, recall, F1-score, and the confusion matrix, not accuracy alone.

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run the cells in order.
