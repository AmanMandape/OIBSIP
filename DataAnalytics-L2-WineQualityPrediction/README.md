# Wine Quality Prediction

## Project Overview
This project uses machine learning to predict wine quality from physicochemical properties such as acidity, residual sugar, chlorides, density, pH, sulphates, and alcohol content.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Activities
- Dataset exploration and quality distribution analysis
- Correlation analysis and heatmap visualization
- Feature preparation and scaling
- Random Forest classification
- Model evaluation using classification metrics
- Feature importance analysis
- Saving prediction results

## Project Contents
- `dataset/` — Wine quality dataset, if included
- `notebook/` — Wine quality prediction notebook
- `output/` — Saved predictions and results

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run the cells in order.
