# OIBSIP — Data Analytics Internship Projects

## About This Repository

Welcome to my **Oasis Infobyte (OIBSIP) Data Analytics Internship Projects** repository.

This repository contains seven projects completed as part of my Data Analytics learning journey. These projects demonstrate practical skills in Python programming, data cleaning, exploratory data analysis (EDA), data visualization, machine learning, and predictive analytics.

## Projects Overview

### Level 1 — Data Analytics

| No. | Project | Description | Key Techniques |
|---|---|---|---|
| 1 | Retail Sales EDA | Analyze retail sales trends, customer demographics, and product category performance. | Pandas, Matplotlib, Seaborn |
| 2 | Customer Segmentation | Group customers according to purchasing behavior. | K-Means Clustering, StandardScaler |
| 3 | Data Cleaning | Identify and handle missing values, duplicates, inconsistencies, and potential outliers. | Pandas, NumPy, Data Validation |
| 4 | Sentiment Analysis | Analyze Amazon product reviews and classify sentiment using review ratings and text features. | Text Preprocessing, TF-IDF, Logistic Regression |

### Level 2 — Machine Learning

| No. | Project | Description | Key Techniques |
|---|---|---|---|
| 5 | House Price Prediction | Predict house prices from property features. | Linear Regression, Data Preprocessing |
| 6 | Wine Quality Prediction | Predict wine quality from physicochemical properties. | Random Forest Classifier, Feature Importance |
| 7 | Fraud Detection | Identify potentially fraudulent transactions in imbalanced transaction data. | Random Forest, Class Balancing, Classification Metrics |

## Technologies and Tools

To run a notebook locally, install the required Python libraries and open it using Jupyter Notebook or Visual Studio Code.
