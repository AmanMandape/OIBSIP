# Amazon Product Reviews Sentiment Analysis

## Project Overview
This project analyzes Amazon product reviews to understand customer opinions and classify reviews as positive, neutral, or negative using review ratings and machine learning.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLTK or text-processing tools, where used
- Jupyter Notebook

## Project Activities
- Review dataset inspection and text preprocessing
- Sentiment labeling based on review scores
- Word frequency analysis
- TF-IDF feature extraction
- Logistic Regression model training
- Model evaluation and confusion matrix
- Product-level sentiment analysis

## Project Contents
- `dataset/` — Review dataset, if included
- `notebook/` — Sentiment analysis notebook
- `output/` — Sentiment analysis results

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run the cells in order. Ensure the required Python libraries are installed.
