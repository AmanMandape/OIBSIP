# Retail Data Cleaning

## Project Overview
This project cleans and prepares a retail sales dataset for reliable analysis by identifying missing values, duplicate records, inconsistent data, and potential outliers.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Activities
- Dataset inspection and data type checks
- Missing-value and duplicate checks
- Data validation and consistency checks
- Outlier analysis
- Data cleaning and quality verification
- Exporting the cleaned dataset

## Project Contents
- `dataset/` — Original dataset, if included
- `notebook/` — Data cleaning notebook
- `output/` — Cleaned dataset and results

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run the cells in order.
