# House Price Prediction

## Project Overview
This project uses machine learning to predict house prices from property features such as area, number of bedrooms and bathrooms, floors, year built, location, condition, and garage information.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Activities
- Dataset exploration and visualization
- Data preprocessing and categorical encoding
- Training and testing data split
- Linear Regression model training
- Prediction and model evaluation using regression metrics
- Actual-versus-predicted price analysis

## Project Contents
- `dataset/` — House price dataset, if included
- `notebook/` — House price prediction notebook
- `output/` — Saved predictions and results

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run the cells in order.
