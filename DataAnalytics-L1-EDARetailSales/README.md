# Retail Sales Exploratory Data Analysis

## Project Overview
This project explores retail sales data to identify sales trends, customer purchasing patterns, and product category performance.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Contents
- `dataset/` — Retail sales dataset
- `notebook/` — Jupyter Notebook containing the analysis
- `output/` — Analysis results and visualizations

## Key Activities
- Data loading and inspection
- Exploratory data analysis
- Sales trend analysis
- Customer and product category analysis
- Data visualization
- Business observations and recommendations

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run its cells in order.
