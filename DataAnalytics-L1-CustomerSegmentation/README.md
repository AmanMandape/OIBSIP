# Customer Segmentation Using K-Means Clustering

## Project Overview
This project groups retail customers into segments based on purchasing behavior using the K-Means clustering algorithm.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Activities
- Customer data aggregation
- Feature scaling using StandardScaler
- K-Means clustering
- Customer segment profiling
- Cluster visualization
- Business recommendations

## Project Contents
- `dataset/` — Retail sales dataset
- `notebook/` — Customer segmentation notebook
- `output/` — Saved results and visualizations, where available

## How to Run
Open the notebook in Jupyter Notebook or Visual Studio Code and run the cells in order.
